# Implementation Plan — bpmn-event-notation-anchor

## 정의
BPMN 이벤트를 표기(원 글자)로 다루기 위해, 배치기의 접점·정렬 기준을 이벤트의 원 글자 칸으로 옮기고 그리기가
원 글자를 노드 원점에 고정하며 종료 글자를 `◉`로 맞추는 수정이다. 손으로 만든 도형·그래프 단위 테스트와 기존
예제 렌더링으로 검증한다.

- [x] 1. 재현 테스트 갱신(수정 전 실패해야 함)
- [x] 1.1 (P) 배치 테스트: 간선이 이벤트의 원 글자 칸에 닿는다
  - 위→아래: `Round "Task"` → 종료 이벤트 이름 `""`·`"Done"`·`"주문 취소"` 세 그래프에서 `▼` 열 == 원 글자 열;
    시작 이벤트 `"Go"` → `Round`에서 `○` 바로 아래 칸이 선; `Round "A"`·`"B"` → 종료 `"Done"`에서 모든 `▼`가
    원 글자 바로 위 칸
  - 왼쪽→오른쪽: 본문 세 줄(`one\ntwo\nthree`) 종료 이벤트, 그리고 같은 노드에 들어오는 간선 둘에서 모든 `▶`가
    원 글자 바로 왼쪽 칸(같은 줄)
  - 기존 두 접점 테스트를 "이벤트가 차지한 열 범위 안" → "원 글자와 같은 열", `●` → `◉`로 강화; 손 그래프
    기대 글자 목록 `●` → `◉`
  - DONE: 새·강화 테스트가 수정 전 코드에서 열·줄 불일치(`4 vs 1`, `1 vs 0`)와 `◉` 부재로 **실패**함을 확인
    (1.1~1.5)
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 2.1, 2.2, 2.3, 2.4, 2.5_
  - _Difficulty: mid_
  - _Boundary: layout::graph 테스트_

- [x] 1.2 (P) 도형 테스트: 종료 글자 `◉`와 원 글자 원점 고정
  - 종료 `"Go"` → `["◉ Go"]`(시작 `○`·중간 `◎`는 그대로); 협업 손 모델·bpmn.io fixture 렌더링의 기대 글자 목록
    `●` → `◉`, "채운 원 글자(●)" 주석 갱신
  - 측정값보다 넉넉한 `min_width`(+4)·`min_height`(+2)로 종료 이벤트 `["Go"]`를 그려도 원 글자가 `(0, 0)`, 이름이
    `(2, 0)`, 여분은 뒤·아래 빈칸
  - DONE: `◉` 리터럴 테스트가 수정 전 `●`라 **실패**, 원점 고정 테스트가 수정 전 `(2, 1)`에 글자가 있어 **실패**함을
    확인(1.6, 2.5)
  - _Requirements: 1.6, 2.5, 2.6_
  - _Difficulty: low_
  - _Boundary: layout::shape 테스트, bpmn::mod 테스트_

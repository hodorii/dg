# Implementation Plan — bpmn-lane-layout

## 정의
기존 그래프 배치기의 그룹에 "레인" 종류를 더해 소속 범위 전체를 관통하는 띠로
그리는 기능이다. 파서 없이 손으로 만든 그래프 단위 테스트로만 검증한다.

- [x] 1. 기반: 그룹 종류와 회귀 기준선
- [x] 1.1 (P) 그룹 종류 `GroupKind { Box, Lane }` 추가
  - 중간 표현의 그룹에 종류 필드를 두고 기본값은 `Box`. 기존 `add_group`/
    `add_group_with_id`는 `Box`를 넣고, 레인 그룹을 만드는 `add_lane(title, parent)`
    은 그 위의 얇은 래퍼(그룹 생성 경로는 한 곳)
  - 그룹을 만드는 기존 파서 5곳(mermaid flow·class·state, PlantUML class·component)
    은 수정하지 않는다
  - DONE: `add_lane`으로 만든 그룹의 종류가 `Lane`, `add_group`으로 만든 그룹은
    `Box`임을 확인하는 단위 테스트가 통과하고, 기존 `cargo test` 전량이 무수정 통과
  - _Requirements: 1.2, 6.1_
  - _Difficulty: low_
  - _Boundary: diagram::ir_

- [x] 1.2 (P) 레인 없는 출력의 바이트 기준선 채취
  - 배치기 수정 전에 `examples/*.md` 전부를 `dg -P --width 100`으로 렌더링해
    스크래치 디렉터리에 저장(4.1의 diff 기준)
  - DONE: 예제 파일마다 기준 출력 파일이 하나씩 존재하고, 같은 명령을 다시 돌려도
    같은 내용이 나온다(결정적 출력 확인)
  - _Requirements: 6.1_
  - _Difficulty: low_
  - _Boundary: 검증_

- [x] 2. 레인 기하(배치기, 모두 같은 파일 — 순차)
- [x] 2.1 층 범위 강제와 형제 나란히 배치
  - 그룹별 유효 층 범위를 한 함수에서 계산(레인은 부모의 유효 범위, 부모 없으면
    첫 층~마지막 층; 일반 그룹은 구성원 범위)해 가상 노드 소속 판정과 블록 층
    범위 양쪽이 같은 값을 쓴다(design §Key Decisions "층 범위" 행)
  - 레인 판별 도우미(루트 블록은 항상 레인 아님)
  - DONE: TB 렌더링에서 최상위 레인 A(노드가 층 0에만)와 레인 B(층 0~2)의 세로
    테두리 줄 수가 같고 두 레인이 좌우로 나란히 있으며, 레인 안에 중첩한 레인의
    테두리도 부모와 같은 층 범위를 덮는 단위 테스트 통과. 일반 그룹만 있는 기존
    테스트(`groups_enclose_members` 등)는 출력 불변
  - _Requirements: 1.1, 1.2, 1.3, 1.4_
  - _Difficulty: high_
  - _Boundary: layout::graph_
  - _Depends: 1.1_

- [x] 2.2 교차축 밀착: 부모와 pad 0, 형제 간격 -1
  - 부모가 레인일 때 레인 자식은 여백 없이 부모 시작 칸에서 시작하고 부모 폭은
    마지막 자식 끝까지; 형제 레인은 앞 레인의 끝 한 칸 앞에서 시작해 경계 칸을
    공유. 노드·일반 그룹 자식은 기존 여백·간격 그대로("교차축" 행)
  - 부모 레인의 라벨 여유(`block_extra`)는 마지막 레인 자식에게 넘기고 자기 폭에는
    더하지 않는다("`block_extra`" 행)
  - DONE: TB 렌더링에서 형제 레인 사이 세로 경계가 `│` 한 열이고(`││` 없음),
    부모 윗변에 `┬`·아랫변에 `┴`가 찍히며, 첫 자식의 왼쪽·마지막 자식의 오른쪽
    테두리 열이 부모 테두리 열과 같음을 확인하는 단위 테스트 통과
  - _Requirements: 2.1, 2.2, 2.3_
  - _Difficulty: high_
  - _Boundary: layout::graph_

- [x] 2.3 흐름축 랭크·레벨과 레인 사각형의 끝
  - 부모가 레인인 레인 블록은 시작 랭크·끝 랭크·층별 상/하 레벨 집계 어디에도
    한 단으로 세지 않는다(테두리가 부모와 한 줄). 최상위 레인은 일반 그룹처럼 셈
    ("랭크·레벨" 행)
  - 레인 사각형의 흐름축 끝은 최상위면 캔버스 끝, 부모가 레인이면 부모의 끝
    ("레인 사각형" 행)
  - DONE: TB 렌더링에서 풀 > 레인 > 하위 레인 3단 중첩의 아랫변이 모두 같은 줄에
    있고, 중첩 단계마다 가로선이 한 줄씩 늘어나는 이중 구분선이 없음을 확인하는
    단위 테스트 통과; 레인 안의 일반 그룹은 기존처럼 안쪽으로 한 단 들어감
  - _Requirements: 1.3, 2.3_
  - _Difficulty: high_
  - _Boundary: layout::graph_

- [x] 2.4 제목 배너와 구분선
  - 깊이별 배너 크기(TB 2줄, LR 3 + 그 깊이 제목 폭 최댓값)와 깊이별 시작
    오프셋을 계산해 첫 층 시작 위치에 합을 더한다("배너 크기"·"오프셋" 행)
  - 레인 사각형은 자기 깊이의 배너 시작에서 그리고, 레인 폭 전체에 기존 그룹
    내용 상자 윗변 위치로 구분선을 긋는다("레인 사각형"·"구분선" 행)
  - 제목은 배너 안(흐름축 배너 시작+1, 교차축 시작+1)에 가로쓰기; TB는 기존 자르기·
    최소 폭 규약 그대로, LR은 자르지 않음; 빈 제목은 쓰지 않음("제목" 행)
  - DONE: 단위 테스트에서 (a) TB 제목 줄이 첫 노드 줄보다 위이고 그 줄에 `─`가
    없음, (b) LR 제목 열이 첫 노드의 왼쪽 테두리보다 왼쪽, (c) 풀 제목이 레인
    제목보다 앞 줄/열, (d) 제목 길이가 다른 형제 레인의 첫 노드 시작 줄/열이 같음,
    (e) TB에서 노드보다 긴 제목이 잘리지 않음, (f) 빈 제목 레인의 배너 줄이 공백
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5, 4.6_
  - _Difficulty: high_
  - _Boundary: layout::graph_

- [x] 2.5 레인 순서·접기·출력 밀기 고정
  - 레인 자식이 하나라도 있는 블록은 무게중심 정렬과 이웃 교환을 건너뛴다; 층
    접기 후보에서 레인 블록은 움직일 수 없다; 도착 노드의 원천 그룹이 레인이면
    "그룹 아래로 밀기"를 하지 않는다("순서·접기"·"출력 밀기" 행)
  - DONE: 단위 테스트에서 (a) A, B, C 선언 + C→A 간선만 있어도 열 순서가 A, B, C,
    (b) 폭을 좁혀 TB 층 접기가 일어나도 레인 열이 나란히 유지되고 레인 안 노드만
    아래로 내려감, (c) A: a1→a2→a3 + a1→b1에서 b1이 a2와 같은 줄
  - _Requirements: 2.4, 2.5, 3.1_

  - _Boundary: layout::graph_

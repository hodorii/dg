# Requirements — markdown-source-view

## 정의
마크다운 문서를 보는 사용자를 위해, 렌더된 화면과 마크다운 문법이 색으로 구분된 원문 화면을
문서 전체 또는 블록 단위로 오가며 볼 수 있고, 화면의 아무 텍스트나 드래그해 선택·복사할 수
있게 하는 기능이다.

## Boundary Context
- **In scope**: 문서 전체를 원문/렌더 화면으로 전환하는 전역 토글 키, 기존 다이어그램 전용
  `o` 토글을 문단·헤딩 등 임의 블록으로 확장, 원문 화면에서 마크다운 문법 요소(헤딩·강조·링크·
  인용·목록 등)를 기존 테마 팔레트로 구분 표시, 마우스 드래그로 화면 텍스트를 선택해 시스템
  클립보드로 복사, 드래그(선택)와 클릭(기존 링크 따라가기·다이어그램 토글 액션)의 구분
- **Out of scope**: 코드펜스 안 프로그래밍 언어 신택스 하이라이팅(별도 라운드, 로드맵의
  `markdown-syntax-highlighting` 항목), 원문 편집(읽기 전용 유지), `--print`(비대화형) 모드의
  원문 토글(원래 한 번 렌더된 결과만 출력하는 모드라 토글 개념 자체가 없음), dg 자체 클립보드
  히스토리·다중 선택 관리(시스템 클립보드 한 슬롯에 맡김)

## Acceptance Criteria

### 1. 전역 원문 토글
- 1.1: [사용자가 전역 원문 토글 키를 누름] → 화면이 문서 전체의 마크다운 원문 표시로 전환됨
- 1.2: [원문 표시 상태에서 같은 키를 다시 누름] → 화면이 렌더된 뷰로 돌아가고 스크롤 위치가
  유지됨
- 1.3: [원문 표시 상태에서 기존 스크롤·검색 키를 사용] → 원문 화면 안에서도 동일하게 동작함
- 1.4: [원문 표시 상태에서 `--watch` 감시로 파일이 변경됨] → 원문 내용도 최신 내용으로 갱신됨
- 1.5: [블록별로 원문이 펼쳐진 상태에서 전역 토글을 켰다가 다시 끔] → 그 전에 개별로 펼쳐 뒀던
  블록 상태가 그대로 유지됨

### 2. 블록별 원문 토글 확장
- 2.1: [다이어그램이 아닌 블록(문단·헤딩·목록·인용 등) 위에서 기존 블록 토글 키·클릭을 사용]
  → 그 블록만 원문으로 펼쳐지고 나머지 화면은 렌더된 그대로 유지됨
- 2.2: [펼쳐진 블록에서 같은 조작을 반복] → 그 블록만 다시 렌더된 형태로 접힘
- 2.3: [다이어그램 블록에서 같은 조작] → 기존 동작(원문 펼침/접힘)이 그대로 유지됨(회귀 없음)
- 2.4: [토글 가능한 블록 경계가 없는 위치(빈 줄 등)에서 같은 조작] → 화면이 바뀌지 않음

### 3. 마크다운 문법 하이라이팅
- 3.1: [원문 화면에 헤딩(`#`)·강조(`**`/`*`)·링크(`[텍스트](url)`)·인용(`>`)·목록(`-`/`1.`)이
  포함됨] → 각 문법 요소가 렌더된 화면과 구분되는 색으로 표시됨
- 3.2: [`--style none`] → 원문 화면은 색 없이 일반 텍스트로 표시되고 문법 요소 구분 자체에는
  영향이 없음(기존 무색 모드 계약 유지)
- 3.3: [코드펜스 블록의 원문] → 여는/닫는 펜스 기호만 다른 문법 요소와 구분 표시되고, 펜스
  안쪽 내용은 언어 문법 하이라이팅 없이 일반 텍스트로 표시됨

### 4. 마우스 텍스트 선택·복사
- 4.1: [사용자가 화면 위에서 마우스 왼쪽 버튼을 누른 채 이동한 뒤 뗌(드래그)] → 지나간 구간의
  텍스트가 화면에 선택된 것으로 표시되고, 뗀 순간 그 텍스트가 시스템 클립보드로 복사되어 다른
  프로그램에 붙여넣을 수 있음
- 4.2: [사용자가 이동 없이 눌렀다 뗌(클릭)] → 기존처럼 그 위치의 링크 따라가기·다이어그램 토글이
  실행됨(회귀 없음)
- 4.3: [원문 화면에서 드래그] → 렌더 화면과 동일하게 선택 표시·클립보드 복사가 됨
- 4.4: [마우스 휠 스크롤] → 기존처럼 화면이 스크롤되고 선택 동작과 충돌하지 않음
- 4.5: [시스템 클립보드 복사를 지원하지 않는 터미널] → 화면상 선택 표시는 그대로 동작하고,
  클립보드 복사만 조용히 안 됨(오류·패닉 없음)

### 5. 회귀
- 5.1: [원문 보기·선택 기능을 전혀 쓰지 않는 기존 세션] → 기존 렌더 화면·키·클릭·검색·감시 모드
  동작이 전과 동일함
- 5.2: [항상] → 어떤 입력에도 패닉하지 않음

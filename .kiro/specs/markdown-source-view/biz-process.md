# BizProcess — markdown-source-view

## 정의
마크다운 문서를 보는 사용자를 위해, 렌더된 화면과 문법이 구분된 원문 화면을 오가며 보고
화면의 텍스트를 드래그해 복사할 수 있게 하는 프로세스이다.

## 가치사슬 매핑
| L1 Process | Unit Process (valueChainRef) | 가치 | 관련 요구사항 |
|------------|------------------------------|------|---------------|
| BP-MARKDOWN-SOURCE-VIEW | VC-DG-VIEW-PAGER | 스크롤·검색·다이어그램 원문 토글로 긴 문서를 화면 하나에서 탐색한다 | 1.1~1.5, 2.1~2.4, 3.1~3.3, 4.1~4.5, 5.1~5.2 |

## L1 Process: 원문을 보고 텍스트를 가져간다 (valueChainRef: VC-DG-VIEW-PAGER)

### L2 Activity: 문서 전체를 원문으로 오간다 (1.1~1.5)
  ### L3 FunctionGroup/UI: 전역 원문 토글
    ### L4 Step: 사용자가 전역 원문 토글 키를 누른다
      ### L5 DetailStep: 화면이 문서 전체의 마크다운 원문으로 바뀌거나 렌더 화면으로 되돌아간다
        Logic(AST):
          - IF 렌더 화면 THEN 원문 화면으로 전환 (1.1)
          - IF 원문 화면 THEN 렌더 화면으로 전환, 스크롤 위치 유지 (1.2)
          - 원문 화면에서도 기존 스크롤·검색 키가 그대로 동작 (1.3)
          - IF 감시 모드 + 파일 변경 THEN 원문 내용도 갱신 (1.4)
          - IF 블록별로 펼쳐 둔 상태 있음 + 전역 토글 왕복 THEN 그 상태 유지 (1.5)

### L2 Activity: 블록 하나만 원문으로 펼쳐 본다 (2.1~2.4)
  ### L3 FunctionGroup/UI: 블록별 원문 토글(다이어그램 전용 토글의 확장)
    ### L4 Step: 사용자가 문단·헤딩 등 블록 위에서 토글 조작(키·클릭)을 한다
      ### L5 DetailStep: 그 블록만 원문/렌더 화면으로 바뀐다
        Logic(AST):
          - IF 블록이 원문 아님 THEN 그 블록만 원문으로 펼침, 나머지는 그대로 (2.1)
          - IF 블록이 원문임 THEN 그 블록만 다시 렌더 화면으로 접음 (2.2)
          - IF 다이어그램 블록 THEN 기존 펼침/접힘 동작 그대로 (2.3, 회귀 없음)
          - IF 토글 가능한 블록 경계가 없는 위치 THEN 화면 변화 없음 (2.4)

### L2 Activity: 원문에서 마크다운 문법을 구분해서 읽는다 (3.1~3.3)
  ### L3 FunctionGroup/UI: 원문 문법 하이라이팅
    ### L4 Step: 사용자가 원문 화면에서 헤딩·강조·링크·인용·목록을 본다
      ### L5 DetailStep: 각 문법 요소가 서로 다른 색으로 보인다
        Logic(AST):
          - IF 색 있는 테마 THEN 문법 요소마다 구분되는 색 (3.1)
          - IF `--style none` THEN 색 없이 일반 텍스트, 문법 구분 자체는 유지 (3.2)
          - IF 코드펜스 THEN 펜스 기호만 구분, 안쪽 내용은 일반 텍스트(언어 하이라이팅 없음) (3.3)

### L2 Activity: 화면 텍스트를 드래그해 복사한다 (4.1~4.5)
  ### L3 FunctionGroup/UI: 마우스 드래그 선택·클립보드 복사
    ### L4 Step: 사용자가 화면 위에서 마우스를 누른 채 이동했다가 뗀다
      ### L5 DetailStep: 지나간 구간이 선택 표시되고 시스템 클립보드로 복사된다
        Logic(AST):
          - IF 누른 채 이동 후 뗌(드래그) THEN 구간 선택 표시 + 클립보드 복사 (4.1)
          - IF 이동 없이 뗌(클릭) THEN 기존 링크 따라가기·다이어그램 토글 그대로 실행 (4.2,
            회귀 없음)
          - IF 원문 화면에서 드래그 THEN 렌더 화면과 동일하게 선택·복사 (4.3)
          - IF 마우스 휠 스크롤 THEN 기존처럼 스크롤, 선택 동작과 충돌 없음 (4.4)
          - IF 터미널이 클립보드 복사를 지원 안 함 THEN 선택 표시는 되지만 복사만 조용히 생략,
            오류 없음 (4.5)

### L2 Activity: 이 기능과 무관한 기존 사용은 그대로 본다 (5.1, 5.2)
  ### L3 FunctionGroup/UI: 기존 페이저 동작
    ### L4 Step: 사용자가 원문 보기·드래그 선택을 쓰지 않고 기존처럼 사용한다
      ### L5 DetailStep: 기존과 동일하게 동작한다, 어떤 입력에도 패닉하지 않는다 (5.1, 5.2)

# Requirements — plantuml-wbs

## 정의
PlantUML `@startwbs` 코드펜스로 작업 분류 체계(WBS)를 문서에 넣어 둔 사용자를
위해, 그 코드펜스가 원문 코드블록으로 물러나지 않고 dg의 기존 계층 그래프
배치기로 문자 그림 트리로 그려지게 하는 기능이다.

## Boundary Context
- **In scope**: `@startwbs`/`@endwbs` 확정 태그 판별, OrgMode 깊이 표기(`*`,
  `**`, `***`, …), 여러 루트(문서 하나에 최상위 `*` 항목이 둘 이상), 상자 없이
  글자만 쓰는 `_` 접미사(`*_`, `**_`, …), `:`/`;`로 감싼 여러 줄 본문, 폭 초과
  시 기존 규약대로 원문 코드블록 대체
- **Out of scope**: 좌우 방향을 동시에 쓰는 산술 표기(`+`/`-`, `++`, `--`)와
  `<`/`>` 방향 강제 — 트리가 뿌리 하나에서 양쪽으로 갈라지는 배치는 기존 계층
  그래프 배치기가 지원하지 않는 새 능력이라 별도 검토 대상. 노드 사이 화살표
  연결(`->`, `-->`, `..>`), 인라인 색상(`[#Color]`), `<style>` 블록, 별칭
  (`as`) — 프로젝트 전체가 `skinparam` 등 꾸밈 지시자를 무시하는 기존 관례를
  그대로 따른다.

## Acceptance Criteria

### 1. 판별과 기본 트리
- 1.1: [PlantUML 코드펜스가 `@startwbs`로 시작할 때] → [다른 PlantUML 종류
  판별 휴리스틱을 거치지 않고 곧장 WBS로 판별된다]
- 1.2: [`*` 하나짜리 루트 아래 `**`·`***`로 깊이가 늘어나는 항목들] → [각 항목이
  바로 위 단계(별표 하나 적은 마지막 항목)의 자식으로 트리에 연결된다]
- 1.3: [`*` 로 시작하는 최상위 항목이 문서에 둘 이상] → [각각 독립된 뿌리로
  같은 그림 안에 함께 그려진다]
- 1.4: [들여쓰기 단계를 건너뛰는 표기(예: `*` 다음 바로 `***`)] → [건너뛴
  중간 단계 없이 직전에 실제로 나온 항목의 자식으로 처리된다]

### 2. 본문 표기
- 2.1: [항목 텍스트가 한 줄일 때] → [그 한 줄이 노드 본문으로 그려진다]
- 2.2: [항목 텍스트가 `:`로 시작해 `;`로 끝나는 여러 줄일 때] → [그 여러 줄이
  한 노드 안에 그대로 여러 줄로 그려진다]
- 2.3: [별표 뒤에 `_`가 붙을 때(예: `**_`)] → [그 항목이 테두리 상자 없이
  글자만으로 그려진다]

### 3. 실패·경계 동작
- 3.1: [`@startwbs`~`@endwbs` 사이에 유효한 항목이 하나도 없을 때] → [원문
  코드블록으로 대체되고 패닉이 나지 않는다]
- 3.2: [트리가 지정한 폭보다 넓을 때] → [기존 다른 그래프형 다이어그램과 같은
  규약(방향 재시도 후 실패하면 원문 코드블록)을 따른다]
- 3.3: [범위 밖 표기(산술 좌우 방향, 화살표, 인라인 색상 등)가 섞여 있을 때] →
  [그 표기 자체는 무시하되(값을 반영하지 않되) 나머지 트리 구조는 패닉 없이
  정상적으로 그려진다]

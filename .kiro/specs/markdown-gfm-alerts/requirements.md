# Requirements — markdown-gfm-alerts

## 정의
GitHub 스타일 문서를 보는 사용자를 위해, `> [!NOTE]` 등 GFM 알림 블록을 종류별로 구분되는
라벨·색으로 보여주는 기능이다.

## Boundary Context
- **In scope**: `pulldown-cmark`의 `Options::ENABLE_GFM` 활성화, `Note`/`Tip`/`Important`/
  `Warning`/`Caution` 다섯 종류의 라벨·색 표현, 일반 인용문과의 시각적 구분
- **Out of scope**: GFM의 다른 기능(alert 외 다른 `ENABLE_GFM` 관련 항목 — 현재 이 플래그가
  다루는 건 alert 블록쿼트뿐), 알림 종류 커스터마이징(새 CLI 플래그·지시자 없음), 다른 미지원
  마크다운 확장(스마트 문장부호 등 — brief.md에서 별도 보류)

## Acceptance Criteria

### 1. 알림 블록 인식
- 1.1: [`> [!NOTE]`로 시작하는 인용문] → Note 알림으로 인식되어 일반 인용문과 다른 스타일로
  렌더링됨
- 1.2: [`> [!TIP]`로 시작하는 인용문] → Tip 알림으로 인식됨
- 1.3: [`> [!IMPORTANT]`로 시작하는 인용문] → Important 알림으로 인식됨
- 1.4: [`> [!WARNING]`로 시작하는 인용문] → Warning 알림으로 인식됨
- 1.5: [`> [!CAUTION]`로 시작하는 인용문] → Caution 알림으로 인식됨
- 1.6: [다섯 종류 각각] → 라벨 텍스트 + 시각적 강조(색상·굵기)의 조합으로 서로 구분됨(dg는
  마크다운 요소를 제목·링크 같은 한두 색 계열로 통일하고 명도·굵기로 구분하는 기존 색상
  철학을 따른다 — 5색 무지개를 새로 만들지 않는다, design.md 참조)
- 1.7: [`--style none`] → 색이 빠져도 라벨 텍스트만으로 다섯 종류가 서로 구분됨(라벨이 유일한
  참 구분 기준)

### 2. 일반 인용문과의 회귀
- 2.1: [`[!...]` 마커가 없는 일반 `>` 인용문] → 기존과 동일하게 렌더링됨
- 2.2: [`[!UNKNOWN]`처럼 다섯 종류에 없는 마커] → 일반 인용문으로 그려지고 마커 텍스트가 본문에
  그대로 보임(기존과 동일 — GFM 파서가 다섯 종류 외엔 인식하지 않음)

### 3. 표시 내용
- 3.1: [알림 블록] → 첫 줄에 종류를 나타내는 라벨이 보이고, 원본 `[!NOTE]` 마커 문자열은 본문에
  중복으로 남지 않음
- 3.2: [알림 블록 안 여러 줄·긴 줄 내용] → 기존 인용문과 동일하게 줄바꿈·줄 접기가 적용됨

### 4. 회귀
- 4.1: [항상] → 어떤 입력에도 패닉하지 않음
- 4.2: [기존 마크다운 테스트] → 전량 통과

# Implementation Plan — bpmn-model

## 정의
세 입력 문법이 공유할 BPMN 의미 모델을 정하고, 구조 규칙 검증 → 기존 레인·도형 어휘로의 변환 →
그래프 배치기 렌더링 경로와 다이어그램 언어 `bpmn` 배선을 만드는 기능이다. 파서 없이 손으로
만든 모델 단위·통합 테스트로만 검증한다.

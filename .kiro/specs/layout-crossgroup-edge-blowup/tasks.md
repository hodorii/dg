# Implementation Plan — layout-crossgroup-edge-blowup

## 정의
subgraph 사이를 가로지르는 간선이 많은 flowchart가 폭에 안 들어갈 때 배치 재시도가
수 초~수십 초로 폭발하는 결함을, 배치 한 번의 비용을 결과 동일한 색인화로 낮추고 접기
재시도의 크기에 절대 상한을 두어 고치는 수정이다. 그려지는 결과는 바꾸지 않는다.

- [ ] 1. 재현 테스트 작성(수정 전 실패해야 함)

    고정)로 만드는 테스트용 생성기를 그래프 배치 테스트 모듈 안에 두고, seed·간선 수·변형
    (기본/허브/사슬/불균등 라벨)을 인자로 받게 한다(2.1·4.1도 같은 가족을 쓴다)
  - 접기 재시도에 들어가 층·구간이 누적되는 seed를 골라 고정한다(`DG_DEBUG=1`로 첫 두 시도가

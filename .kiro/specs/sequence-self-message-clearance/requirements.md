# Requirements — sequence-self-message-clearance

## 정의
시퀀스 다이어그램에서 자기 자신에게 보내는 재귀 메시지(self-message)를 읽는 사용자를 위해, 화살촉과 루프의 세로 연결선(모서리) 사이에 시각적으로 구분되는 여백을 두어 렌더링하는 기능이다.

## Boundary Context
- **In scope**: self-message(재귀) 루프의 폭·화살촉 배치 조정, 인접 참가자 컬럼과의 폭 재계산
- **Out of scope**: 일반(비재귀) 메시지 레이아웃, 프래그먼트/노트 레이아웃, 시퀀스 이외 다이어그램 종류

## Acceptance Criteria

### 1. 여백
- 1.1: [self-message(`A->>A`) 렌더링] → 화살촉은 도착 지점인 생명선에 바로 붙고(다른 메시지가 상대 생명선에 바로 닿는 것과 같은 관례), 화살촉과 루프의 세로 연결선(모서리) 사이에 최소 1칸의 수평선이 표시됨(모서리의 굽은 모양이 화살촉에 눌리지 않음)
- 1.2: [self-message에 다양한 화살표 종류(실선/점선, 화살촉 모양) 조합] → 모든 조합에서 화살촉-모서리 사이 여백이 유지됨

### 2. 폭 계산
- 2.1: [self-message가 있는 참가자 바로 오른쪽에 다른 참가자 존재] → 넓어진 루프가 옆 생명선과 겹치지 않도록 참가자 간 폭이 재계산됨
- 2.2: [넓어진 루프를 포함해도 지정 폭 안에 들어감] → 정상적으로 렌더링됨
- 2.3: [넓어진 루프 때문에 지정 폭을 초과함] → 기존 폭 재시도 계약(레이블 폭 축소 등)에 따라 재시도되고, 그래도 안 되면 원문 코드블록으로 대체됨(패닉 없음)

### 3. 회귀
- 3.1: [기존 self-message 렌더링 테스트] → 여백이 추가된 새 레이아웃 기준으로 기존 테스트가 갱신되어 통과함
- 3.2: [항상] → 어떤 입력에도 비정상 종료(패닉)하지 않음

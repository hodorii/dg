# Requirements — mermaid-gitgraph

## 정의
커밋/브랜치 흐름을 mermaid `gitGraph` 문법으로 표현하려는 사용자를 위해, 코드펜스 안 `gitGraph` 소스를 브랜치 트랙과 커밋 점으로 이루어진 터미널 텍스트 다이어그램으로 그려주는 기능이다.

## Boundary Context
- **In scope**: `gitGraph` 판별, `commit`/`branch`/`checkout`(`switch`)/`merge` 파싱과 트랙 배치, 커밋 순서 보존, 표시 실패 시 일반 코드블록 대체
- **Out of scope**: `cherry-pick`을 포함한 세부 스타일 옵션(색상·아이콘), 실제 git 저장소 연동, 커밋 그래프 편집

## Acceptance Criteria

### 1. 종류 판별
- 1.1: [첫 지시어가 gitGraph(콜론 포함 여부 무관)] → gitgraph 종류로 판별되어 렌더링 시도됨

### 2. 기본 흐름
- 2.1: [commit 문 나열, branch 없음] → 하나의 트랙 위에 커밋 점들이 순서대로 좌에서 우로 배치되어 표시됨
- 2.2: [branch <이름> 정의] → 새 트랙이 추가되어 표시됨
- 2.3: [checkout 또는 switch <이름>으로 트랙 전환 후 commit] → 전환된 트랙 위치에 커밋이 표시됨

### 3. 병합
- 3.1: [merge <브랜치> 정의] → 두 트랙 사이에 병합선이 표시됨
- 3.2: [병합 대상 브랜치가 정의되지 않음] → 오류 없이 병합선 없이 나머지 부분만 표시됨

### 4. 라벨
- 4.1: [branch에 이름 포함] → 트랙 옆에 브랜치 이름이 표시됨
- 4.2: [commit id: "..." 지정] → 커밋 점 옆 또는 위에 해당 id 텍스트가 표시됨

### 5. 경계/오류 처리
- 5.1: [트랙 수 증가로 표시 폭 초과] → gitgraph 대신 일반 코드블록으로 표시됨
- 5.2: [정의되지 않은 브랜치로 checkout] → 오류 없이 새 트랙으로 처리되거나 일반 코드블록으로 대체 표시됨
- 5.3: [항상] → 어떤 입력에도 비정상 종료(패닉)하지 않음

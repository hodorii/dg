# Requirements — dg-watch-mode

## 정의
파일을 편집하며 dg로 미리보기를 확인하는 사용자를 위해, 파일이 바뀔 때마다 자동으로 다시
렌더링해 보여주는 기능이다.

## Boundary Context
- **In scope**: `--watch`/`-W` CLI 플래그, 파일 경로 입력에서의 변경 감지(폴링 기반), 페이저 모드·
  print 모드 양쪽 지원, 페이저에서 스크롤 위치 유지와 수동 갱신 키, 파일 읽기 실패 시 상태 표시 후
  계속 감시, 신규 의존성 없이 구현(폴링만, `notify` 등 OS 이벤트 크레이트 도입 안 함)
- **Out of scope**: 표준입력(stdin) 감시, 다이어그램 언어 자동판별의 재갱신(최초 판별 유지),
  여러 파일 동시 감시, 편집기별 저장 방식(원자적 저장·심볼릭 링크)에 대한 특수 처리(경로를 매번
  다시 읽으므로 별도 요구사항 없이 자연히 커버됨)

## Acceptance Criteria

### 1. 활성화
- 1.1: [`--watch` 없이 실행] → 기존과 동일하게 한 번만 렌더링됨(회귀 없음)
- 1.2: [`--watch` + 파일 경로 지정] → 감시 모드로 실행됨
- 1.3: [`--watch` + 표준입력(파일 미지정 또는 `-`)] → 표준입력을 읽으려 시도하지 않고, 감시할 파일이
  없다는 오류 메시지와 함께 0이 아닌 종료 코드로 끝남

### 2. 변경 감지 및 재렌더링(공통)
- 2.1: [감시 중 파일 내용이 바뀜] → 1초 이내에 새 내용으로 다시 렌더링됨
- 2.2: [감시 중 파일 내용이 바뀌지 않음] → 화면이 다시 그려지지 않음
- 2.3: [항상] → 감시 대상 파일 이외의 어떤 파일도 생성·수정·삭제하지 않음

### 3. 페이저 모드
- 3.1: [페이저로 감시 중 파일이 바뀜] → 사용자가 보던 스크롤 위치(맨 위 줄 기준)가 유지된 채
  내용만 갱신됨(문서가 짧아져 위치를 벗어나면 끝으로 조정)
- 3.2: [페이저로 감시 중 사용자가 키를 입력] → 파일 변경 감지와 무관하게 즉시 반응함(입력 지연 없음)
- 3.3: [페이저로 감시 중 `q` 입력] → 감시를 멈추고 기존과 동일하게 종료함
- 3.4: [페이저 감시 모드] → 상태 표시줄에 감시 중임이 표시됨
- 3.5: [페이저 감시 모드에서 `r` 입력] → 파일 변경 여부와 무관하게 즉시 다시 읽어 재렌더링됨(수동 갱신)

### 4. print 모드
- 4.1: [`-P`(또는 파이프)와 `--watch` 함께 지정] → 파일이 바뀔 때마다 새 렌더링 결과가 표준출력에
  다시 쓰임
- 4.2: [print 모드로 감시 중 `Ctrl-C`] → 프로세스가 종료됨

### 5. 오류 처리
- 5.1: [감시 중 파일이 삭제되거나 읽기 실패] → 패닉·비정상 종료 없이 마지막으로 성공한 렌더링을
  유지한 채, 페이저 모드는 상태 표시줄에 "감시 불가" 표시(print 모드는 stderr 메시지)로 알림
- 5.2: [파일이 다시 읽을 수 있는 상태로 돌아옴] → 별도 조작 없이 자동으로 갱신이 재개됨
- 5.3: [항상] → 어떤 입력·파일 상태에도 패닉하지 않음

### 6. 회귀
- 6.1: [`--watch` 없는 기존 페이저·print 사용] → 기존 동작(스크롤·검색·원문 토글·창 크기 반응 등)이
  그대로 유지됨

# BizProcess — dg-watch-mode

## 정의
파일을 편집하며 dg로 미리보기를 확인하는 사용자를 위해, 파일이 바뀔 때마다 자동으로 다시
렌더링해 보여주는 프로세스이다.

## 가치사슬 매핑
| L1 Process | Unit Process (valueChainRef) | 가치 | 관련 요구사항 |
|------------|------------------------------|------|---------------|
| BP-DG-WATCH-MODE | VC-DG-VIEW-WATCH | dg를 다시 실행하지 않고도 편집 중인 파일의 최신 내용을 계속 본다 | 1.1~1.3, 2.1~2.3, 3.1~3.5, 4.1~4.2, 5.1~5.3, 6.1 |

## L1 Process: 파일을 편집하며 자동 갱신되는 미리보기를 본다 (valueChainRef: VC-DG-VIEW-WATCH)

### L2 Activity: 감시 모드를 켠다 (1.1, 1.2, 1.3, 6.1)
  ### L3 FunctionGroup/UI: 명령줄 입력
    ### L4 Step: 사용자가 `dg --watch 파일` 또는 `dg -P --watch 파일`을 실행한다
      ### L5 DetailStep: dg가 플래그와 파일 경로 유무를 확인한다
        Logic(AST):
          - IF `--watch` 없음 THEN 기존과 동일하게 한 번만 렌더링됨 (6.1)
          - ELSE IF 파일 경로 있음 THEN 감시 모드로 시작함 (1.2)
          - ELSE (표준입력이거나 파일 미지정) THEN 표준입력을 읽지 않고 오류 메시지와 함께
            비정상 종료함 (1.3)

### L2 Activity: 파일이 바뀌면 자동으로 다시 본다 (2.1, 2.2, 2.3)
  ### L3 FunctionGroup/UI: 감시 루프(백그라운드)
    ### L4 Step: 사용자가 원본 파일을 편집기에서 저장한다
      ### L5 DetailStep: dg가 주기적으로 파일 상태를 확인한다
        Logic(AST):
          - IF 파일 내용이 바뀜 THEN 1초 이내에 다시 읽어 재렌더링함 (2.1)
          - ELSE 화면을 다시 그리지 않음 (2.2)
          - 항상: 감시 대상 파일 이외의 어떤 파일도 생성·수정·삭제하지 않음 (2.3)

### L2 Activity: 페이저로 보면서 편집을 이어간다 (3.1, 3.2, 3.3, 3.4, 3.5)
  ### L3 FunctionGroup/UI: 페이저 화면·상태 표시줄
    ### L4 Step: 사용자가 스크롤·검색을 계속하며 파일이 갱신되는 것을 지켜본다
      ### L5 DetailStep: 파일이 바뀌면 스크롤 위치를 유지한 채 내용만 갱신한다 (3.1)
      ### L5 DetailStep: 상태 표시줄에서 감시 중임을 확인한다 (3.4)
      ### L5 DetailStep: 키를 누르면 파일 변경 감지와 무관하게 즉시 반응을 본다 (3.2)
        Logic(AST):
          - IF 사용자가 `r` 입력 THEN 파일 변경 여부와 무관하게 즉시 다시 읽어 재렌더링함 (3.5)
          - IF 사용자가 `q` 입력 THEN 감시를 멈추고 기존과 동일하게 종료함 (3.3)

### L2 Activity: print 모드로 계속 지켜본다 (4.1, 4.2)
  ### L3 FunctionGroup/UI: 표준출력
    ### L4 Step: 사용자가 `dg -P --watch 파일`을 실행해 두고 다른 창에서 편집한다
      ### L5 DetailStep: 파일이 바뀔 때마다 새 렌더링 결과가 표준출력에 다시 쓰이는 것을 본다 (4.1)
      ### L5 DetailStep: 그만 보고 싶으면 `Ctrl-C`로 끝낸다 (4.2)

### L2 Activity: 파일을 잠깐 못 읽는 동안에도 안심하고 기다린다 (5.1, 5.2, 5.3)
  ### L3 FunctionGroup/UI: 오류 상태 표시
    ### L4 Step: 저장 도중 dg가 파일을 읽으려는 순간 파일이 일시적으로 없거나 읽기 실패한다
      ### L5 DetailStep: 화면(또는 stderr)에서 "감시 불가" 같은 상태를 본다
        Logic(AST):
          - IF 읽기 실패 THEN 마지막으로 성공한 렌더링을 그대로 유지, 오류 상태를 알림, 패닉하지
            않음 (5.1, 5.3)
          - IF 파일이 다시 읽을 수 있는 상태로 돌아옴 THEN 별도 조작 없이 자동으로 갱신이 재개됨
            (5.2)

# Requirements — mermaid-xychart

## 정의
수치 추이를 mermaid `xychart-beta` 문법으로 표현하려는 사용자를 위해, 코드펜스 안 `xychart-beta` 소스를 X/Y 축 기반 막대·선 그래프로 이루어진 터미널 텍스트 차트로 그려주는 기능이다.

## Boundary Context
- **In scope**: `xychart-beta` 판별, `title`, `x-axis`(카테고리 목록), `y-axis`(제목+범위), `bar`/`line` 데이터 계열(복수 계열 포함), 공통 차트 렌더링 규칙 적용, 표시 실패 시 일반 코드블록 대체
- **Out of scope**: 곡선 보간(스무딩), 다중 y축, 실시간 갱신

## Acceptance Criteria

### 1. 종류 판별
- 1.1: [첫 지시어가 xychart-beta] → xychart 종류로 판별되어 렌더링 시도됨

### 2. 축 표시
- 2.1: [x-axis에 카테고리 목록 지정] → 가로축에 각 카테고리 라벨이 순서대로 표시됨
- 2.2: [y-axis에 제목과 최소~최대 범위 지정] → 세로축에 제목과 눈금 값이 표시됨
- 2.3: [y-axis 범위 미지정] → 데이터 값 범위로부터 자동 계산된 눈금이 표시됨

### 3. 데이터 계열
- 3.1: [bar [...] 계열 데이터] → 각 카테고리 위치에 값 크기에 비례한 막대가 표시됨
- 3.2: [line [...] 계열 데이터] → 각 카테고리 지점을 잇는 선(또는 점 궤적)이 표시됨
- 3.3: [bar와 line이 함께 정의됨] → 두 계열이 구분 가능한 형태로 같은 축 위에 표시됨
- 3.4: [계열 데이터 개수가 카테고리 개수와 다름] → 오류 없이 부족한 부분은 생략되거나 일반 코드블록으로 대체 표시됨

### 4. 제목
- 4.1: [title <텍스트> 지정] → 차트 위에 제목이 표시됨

### 5. 경계/오류 처리
- 5.1: [카테고리 수가 표시 가능한 가로 폭 초과] → 일반 코드블록으로 대체 표시됨
- 5.2: [값에 음수 포함] → 기준선 아래로 표시되어 구분됨
- 5.3: [항상] → 어떤 입력에도 비정상 종료(패닉)하지 않음

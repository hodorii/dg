# BizProcess — markdown-link-navigation

## 정의
마크다운 문서를 보는 사용자를 위해, 문서 안 링크를 따라 헤딩 점프·브라우저 열기·다른 파일
이동을 할 수 있게 하는 프로세스이다.

## 가치사슬 매핑
| L1 Process | Unit Process (valueChainRef) | 가치 | 관련 요구사항 |
|------------|------------------------------|------|---------------|
| BP-MARKDOWN-LINK-NAVIGATION | VC-DG-VIEW-PAGER | 스크롤·검색·원문 토글로 긴 문서를 화면 하나에서 탐색한다 | 1.1~1.5, 2.1~2.4, 3.1~3.2, 4.1~4.8, 5.1~5.2 |

## L1 Process: 링크를 따라 문서 안팎을 오간다 (valueChainRef: VC-DG-VIEW-PAGER)

### L2 Activity: 마우스·키보드로 링크를 고른다 (1.1~1.5)
  ### L3 FunctionGroup/UI: 링크 포커스·클릭
    ### L4 Step: 사용자가 화면에 보이는 링크 중 하나를 고른다
      ### L5 DetailStep: 마우스로 클릭하거나, 키보드로 다음/이전 링크 이동 키를 눌러 포커스를
        옮긴다
        Logic(AST):
          - IF 링크 있음 THEN 클릭 위치 판정 또는 포커스 이동+시각적 강조 (1.1~1.3)
          - IF 화면에 링크 없음 THEN 이동 키가 아무 효과 없음 (1.4)
      ### L5 DetailStep: 확정 키(또는 클릭)로 고른 링크를 따라간다 → 종류별 동작 실행 (1.5)

### L2 Activity: 문서 내 헤딩으로 점프한다 (2.1~2.4)
  ### L3 FunctionGroup/UI: 앵커 링크
    ### L4 Step: 사용자가 `#section` 링크를 따라간다
      ### L5 DetailStep: 화면이 그 헤딩으로 스크롤된다
        Logic(AST):
          - IF 슬러그가 문서 헤딩과 일치 THEN 그 줄로 스크롤 (2.1)
          - 슬러그는 GitHub 규칙(소문자·하이픈·중복 접미사)으로 생성됨 (2.2, 2.3)
          - IF 슬러그가 없음 THEN 상태 메시지로 알리고 위치 유지, 패닉 없음 (2.4)

### L2 Activity: 외부 링크를 브라우저로 연다 (3.1, 3.2)
  ### L3 FunctionGroup/UI: 외부 URL 링크
    ### L4 Step: 사용자가 `http(s)://` 링크를 따라간다
      ### L5 DetailStep: OS 기본 브라우저가 열린다
        Logic(AST):
          - IF 브라우저 실행 성공 THEN 그 URL이 열림 (3.1)
          - IF 실행 실패(헤드리스 등) THEN 상태 메시지로 알림, 페이저는 계속 동작 (3.2)

### L2 Activity: 다른 문서로 넘어갔다 되돌아온다 (4.1~4.8)
  ### L3 FunctionGroup/UI: 파일 링크·뒤로/앞으로
    ### L4 Step: 사용자가 다른 `.md` 파일 링크를 따라가고, 필요하면 뒤로/앞으로 오간다
      ### L5 DetailStep: 파일이 바뀌어 화면에 나타난다
        Logic(AST):
          - IF 파일 입력 + 상대경로 파일 존재 THEN 그 파일로 화면이 바뀜, 감시 중이면 감시
            대상도 갱신 (4.1, 4.4)
          - IF 표준입력으로 받은 문서 THEN 이동하지 않고 안내 메시지 (4.2)
          - IF 파일 없음/읽기 실패 THEN 상태 메시지, 기존 화면 유지 (4.3)
      ### L5 DetailStep: 뒤로/앞으로 키로 방문 기록을 오간다
        Logic(AST):
          - IF 뒤로 THEN 이전 파일·위치로 복귀 (4.5), 히스토리 없으면 무동작 (4.7)
          - IF 뒤로 간 뒤 앞으로 THEN 다시 다음 위치로 (4.6)
          - IF 히스토리 중간에서 새 링크를 따라감 THEN 그 이후 "앞으로" 기록은 버려짐 (4.8)

### L2 Activity: 감시 없는 기존 사용은 그대로 본다 (5.1, 5.2)
  ### L3 FunctionGroup/UI: 기존 페이저 동작
    ### L4 Step: 사용자가 이 기능과 무관하게 기존처럼 스크롤·검색·원문 토글을 쓴다
      ### L5 DetailStep: 기존과 동일하게 동작한다, 어떤 입력에도 패닉하지 않는다 (5.1, 5.2)

### ✅ 검토 요청 (L1: 링크를 따라 문서 안팎을 오간다)
승인(✓) 또는 수정 사항을 입력하세요.

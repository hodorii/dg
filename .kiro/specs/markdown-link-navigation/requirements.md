# Requirements — markdown-link-navigation

## 정의
마크다운 문서를 보는 사용자를 위해, 문서 안 링크를 따라 문서 내 헤딩으로 점프하거나 외부
브라우저를 열거나 다른 `.md` 파일로 이동(뒤로/앞으로 히스토리 포함)할 수 있게 하는 기능이다.

## Boundary Context
- **In scope**: 링크 위치 인식(마우스 클릭·키보드 포커스 이동 공통 기반), 문서 내 앵커(`#헤딩`)
  점프, 외부 URL을 OS 기본 브라우저로 열기, 다른 `.md` 파일로 이동 + back/forward 히스토리
- **Out of scope**: 디렉터리 브라우징/파일 선택 UI(1차 discovery의 "파일브라우저" 배제 유지),
  코드펜스 신택스 하이라이팅(별도 라운드), lazy/뷰포트 파싱 전환(불필요 판단, brief.md 참조),
  표준입력으로 받은 문서에서의 파일 간 이동(경로 기준 없음)

## Acceptance Criteria

### 1. 링크 위치 인식(공통 기반)
- 1.1: [문서에 링크가 하나 이상 있음] → 페이저가 각 링크의 화면 위치와 목적지를 알고 있어
  마우스 클릭 판정이 가능함
- 1.2: [키보드로 "다음 링크" 이동 키를 누름, 포커스된 링크 없음] → 현재 화면에 보이는 첫 링크가
  포커스되어 시각적으로 강조됨
- 1.3: [포커스된 링크가 있는 상태에서 "다음/이전 링크" 이동 키를 누름] → 화면에 보이는 링크들
  사이에서 포커스가 다음/이전으로 옮겨감
- 1.4: [화면에 링크가 하나도 없음] → 링크 이동 키를 눌러도 아무 일도 일어나지 않음(패닉 없음)
- 1.5: [링크가 포커스된 상태에서 확정 키를 누름] → 그 링크의 종류(앵커/외부/파일)에 맞는 동작이
  실행됨

### 2. 문서 내 앵커 점프
- 2.1: [`[텍스트](#헤딩-슬러그)` 링크를 클릭하거나 포커스 후 확정] → 해당 헤딩이 있는 줄로 화면이
  스크롤됨
- 2.2: [헤딩 텍스트로부터 슬러그를 만드는 규칙] → GitHub 스타일(소문자화, 공백을 하이픈으로,
  영문·숫자·하이픈 외 문자 제거)과 일치해, GitHub에서 쓰던 `#section` 링크가 dg에서도 그대로
  작동함
- 2.3: [같은 제목의 헤딩이 문서에 여러 개 있음] → 각 헤딩이 서로 다른 슬러그를 가짐(GitHub처럼
  두 번째부터 `-1`/`-2` 접미사)
- 2.4: [링크가 가리키는 슬러그가 문서에 없음] → 패닉·화면 깨짐 없이 상태 메시지로 알리고 현재
  위치를 유지함

### 3. 외부 URL 열기
- 3.1: [`http://`/`https://`로 시작하는 링크를 클릭하거나 포커스 후 확정] → OS 기본 브라우저가
  그 URL로 열림
- 3.2: [브라우저를 실행할 수 없는 환경(헤드리스 등)] → 패닉 없이 상태 메시지로 알리고 페이저는
  계속 동작함

### 4. 다른 파일로 이동
- 4.1: [파일 경로로 실행 중(표준입력 아님), 상대 경로의 `.md` 링크를 클릭하거나 포커스 후 확정]
  → 현재 파일 기준 상대 경로로 그 파일을 찾아 읽어 페이저 내용이 그 파일로 바뀜
- 4.2: [표준입력으로 문서를 받은 상태에서 파일 링크를 선택] → 이동하지 않고 상태 메시지로
  "표준입력에서는 파일 이동을 지원하지 않음"을 알림
- 4.3: [링크가 가리키는 파일이 없거나 읽기 실패] → 패닉 없이 상태 메시지로 알리고 기존 화면을
  유지함
- 4.4: [`--watch` 감시 모드에서 다른 파일로 이동] → 감시 대상이 새로 연 파일로 바뀌고, 원래
  파일 감시는 멈춤
- 4.5: [다른 파일로 이동한 뒤 "뒤로" 키] → 이전 파일과 그때 보던 스크롤 위치로 돌아감
- 4.6: [뒤로 간 뒤 "앞으로" 키] → 뒤로 가기 전의 파일·위치로 다시 돌아감
- 4.7: [히스토리가 없는 첫 문서에서 "뒤로" 키] → 아무 일도 일어나지 않음(에러 없음)
- 4.8: [뒤로 간 상태(히스토리 중간)에서 새 링크를 따라감] → 그 지점 이후의 "앞으로" 히스토리는
  버려짐(웹 브라우저와 동일한 관례)

### 5. 회귀
- 5.1: [`--watch` 없는 기존 페이저 사용] → 기존 스크롤·검색·다이어그램 원문 토글 동작이 그대로
  유지됨
- 5.2: [항상] → 어떤 입력에도 패닉하지 않음

# Render Comparison — bpmn-gateway-fixed-size

## 정의
게이트웨이 크기 정책(현행 내용 적응형 vs 고정 크기 후보)을 사용자가 실물로 판단하기 위해, 같은 입력을
현행 바이너리와 일회용 프로토타입 빌드로 그린 결과를 원문 그대로 모은 증거 자료다. 분석·결론은
`research.md`, 수용 기준은 `requirements.md`(200줄 상한 때문에 분리).

## 채취 조건
- 현행: `main` `cbfd774`의 `target/release/dg`. 후보: 같은 커밋을 격리 `git worktree`에 체크아웃해
  `Shape::Gateway` 변형을 덧댄 프로토타입(4파일 +83/−5줄, 실험 후 worktree 삭제, 본체 무변경).
- 공통 옵션 `-P -s none`. 폭·방향은 표본별 제목에 표기. 입력 XML은 `research.md` §Research Log.
- 후보 A = 기호 한 글자만(이벤트 패턴 그대로, 접점 = 원점 칸). 후보 B = 고정 5×3 마름모, 기호 안,
  이름 오른쪽 가운데 줄, 접점 = 마름모 중심. 후보 C = B와 같되 이름은 마름모 아래.

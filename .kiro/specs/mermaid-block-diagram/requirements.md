# Requirements — mermaid-block-diagram

## 정의
마크다운에 mermaid `block-beta` 문법으로 박스/그리드 구조를 표현하려는 사용자를 위해, 코드펜스 안 `block-beta` 소스를 터미널 텍스트 다이어그램으로 그려주는 렌더링 기능이다.

## Boundary Context
- **In scope**: `block-beta` 키워드 판별, `columns` 배치, 블록 라벨/모양, 블록 폭 병합(span), 블록 간 화살표, `block ... end` 중첩 그룹, 표시 실패 시 일반 코드블록 대체
- **Out of scope**: mermaid 공식 스펙 밖의 커스텀 확장, `classDef`/`style`을 통한 색상 커스터마이징, 실제 그래픽/이미지 출력

## Acceptance Criteria

### 1. 종류 판별
- 1.1: [코드펜스 언어가 mermaid이고 첫 유효 지시어가 block-beta] → block 종류로 판별되어 렌더링 시도됨
- 1.2: [소스에 block-beta 지시어가 없음] → block 종류로 판별되지 않아 기존 종류 판별 결과에 영향 없음

### 2. 기본 레이아웃
- 2.1: [columns N 지정 + 블록 나열] → 지정한 열 수만큼 한 행에 배치되어 표시됨
- 2.2: [columns 지정 없음] → 기본 가로 배치로 표시됨
- 2.3: [블록에 라벨 텍스트 포함] → 박스 안에 라벨 텍스트가 표시됨
- 2.4: [블록 span 지정(예: b:2)] → 해당 블록이 지정한 열 수만큼 가로로 넓게 표시됨

### 3. 관계 표현
- 3.1: [블록 간 화살표(-->) 정의] → 두 블록 사이에 연결선이 표시됨
- 3.2: [화살표에 라벨 텍스트 포함] → 연결선 위 또는 옆에 라벨이 표시됨

### 4. 중첩/그룹
- 4.1: [block ... end로 블록 묶음 정의] → 하위 블록들이 하나의 테두리 안에 그룹으로 표시됨
- 4.2: [중첩 그룹이 2단 이상] → 각 단계가 구분 가능한 테두리로 표시됨

### 5. 경계/오류 처리
- 5.1: [렌더링 결과 폭이 표시 가능한 폭을 초과] → block 다이어그램 대신 원본 소스가 담긴 일반 코드블록으로 표시됨
- 5.2: [블록 정의 구문이 비어있거나 불완전] → 오류 메시지 없이 빈 다이어그램 또는 일반 코드블록으로 표시됨
- 5.3: [항상] → 어떤 입력에도 비정상 종료(패닉)하지 않음

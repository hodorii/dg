# Requirements — sequence-nested-activation-offset

## 정의
시퀀스 다이어그램을 읽는 사용자를 위해, 한 참여자가 동시에 여러 겹으로 활성화됐을 때
(겹치는 두 개 이상의 호출이 아직 끝나지 않은 구간) 그 겹침이 화면에서 구분되도록 활성화
막대를 UML 관례대로 옆으로 어긋나게(계단식) 그리는 `diagram::layout::sequence`의
렌더링 기능이다.

## Boundary Context
- **In scope**: 같은 참여자에 대해 동시에 열려 있는 활성화 구간이 2개 이상일 때, 각
  구간을 서로 다른 칸에 그려 겹침 정도를 구분되게 표시. 그만큼 필요한 가로 칸을
  참여자 간격 계산에 반영. 활성화를 열고/닫는 메시지 화살표가 그 활성화의 칸을
  정확히 가리키도록 조정.
- **Out of scope**: 자기 자신에게 보내는 메시지(`from == to`)의 활성화 처리(현재
  레이아웃에서 `activate`/`deactivate` 플래그 자체가 무시되는 별도 기존 결함 —
  이 스펙이 손대지 않음). 프래그먼트(`alt`/`opt`/`loop`) 테두리 선패턴(검토 완료,
  현재 상태 유지로 이미 결정). 생명선 선패턴(검토 완료, 현재 상태 유지로 이미 결정).
  겹침이 없는(항상 1겹뿐인) 기존 다이어그램의 외형 변경.

## Acceptance Criteria

### 1. 겹치는 활성화의 시각적 구분
- 1.1: [한 참여자에게 겹치는 활성화 구간이 정확히 2개일 때] → [두 번째(안쪽) 구간의
  활성화 막대가 첫 번째(바깥쪽) 구간과 다른 칸에, 참여자의 생명선 칸을 기준으로 옆으로
  한 칸 이상 어긋나 그려진다]
- 1.2: [겹치는 활성화 구간이 3개 이상일 때] → [구간마다 이전 구간보다 한 칸씩 더
  어긋나 그려져 몇 겹인지 눈으로 구분된다]
- 1.3: [한 참여자에게 활성화 구간이 겹치지 않고 하나씩만 있을 때(기존과 동일한 경우)]
  → [활성화 막대가 지금과 똑같이 참여자의 생명선 칸에 그려진다(외형 변화 없음)]

### 2. 참여자 간격 확보
- 2.1: [어떤 참여자의 최대 동시 활성화 겹침 수가 N일 때] → [그 참여자와 옆 참여자
  사이 간격이 N겹의 활성화 막대가 서로 겹치거나 옆 참여자의 생명선과 겹치지 않을
  만큼 넓어진다]
- 2.2: [모든 참여자의 활성화가 겹치지 않을 때(N=1)] → [참여자 간격이 지금과 동일하게
  유지된다(불필요한 여백 추가 없음)]

### 3. 메시지 화살표와 활성화 칸의 일치
- 3.1: [메시지가 어떤 참여자를 새로 활성화시켜 겹침이 시작될 때] → [그 메시지 화살표의
  도착 지점이 새로 열리는 활성화 구간의 칸(어긋난 칸)을 정확히 가리킨다]
- 3.2: [메시지가 겹쳐 있던 활성화 중 가장 안쪽(가장 최근에 열린) 것을 닫을 때] →
  [그 메시지 화살표의 출발 지점이 닫히는 활성화 구간의 칸을 정확히 가리킨다]

### 4. 겹침 정도의 상한
- 4.1: [한 참여자의 동시 겹침 수가 이 기능이 지원하는 상한(예: 4겹)을 넘을 때] →
  [그 이상의 겹침은 화면이 지나치게 넓어지지 않도록 상한 칸에서 더 어긋나지 않고
  겹쳐 그려지되, 다이어그램 렌더링 자체는 패닉이나 실패 없이 끝까지 완료된다]

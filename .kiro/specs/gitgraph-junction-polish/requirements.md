# Requirements — gitgraph-junction-polish

## 정의
gitGraph를 읽는 사용자를 위해, 분기·병합 연결선이 트랙 선과 만나는 모서리를 둥글게 그리고,
세로 모드에서 분기 연결선과 커밋 id 글자 사이에 최소 간격을 두는 기능이다.

## Boundary Context
- **In scope**: `diagram::layout::gitgraph`의 분기·병합 연결선이 만드는 2비트 모서리(꺾이는
  지점 하나)를 `canvas`의 기존 `round` 메커니즘으로 둥글게 그림(가로·세로 모드 모두), 세로
  모드에서 분기 연결선이 부모의 가장 최근 커밋과 같은 행에서 그려질 때 그 커밋 id 글자와의
  최소 간격 확보
- **Out of scope**: 한 지점에서 브랜치 3개 이상이 갈라지는 T자·교차 지점(`┳`/`┣`/`┼` 등 —
  `canvas.rs`의 기존 `line_char`가 이 조합에는 애초에 `round`를 반영하지 않음, 새로 반영하지
  않음), 병합 대상(target) 쪽 지점(항상 병합 커밋 점 `◉` 글자가 그 자리를 덮어써 모서리 자체가
  안 보임 — 변경할 필요 없음), 다른 다이어그램형의 모서리, 가로 모드의 커밋 id 간격(재현되지
  않음 — 분기 연결선이 세로선이라 같은 행의 글자와 겹치는 열이 다름), 사용자가 둥근 모서리를
  끄고 켜는 옵션(새 CLI 플래그 없음 — 항상 적용)

## Acceptance Criteria

### 1. 분기·병합 연결선 모서리
- 1.1: [가로 모드(LR/RL), 분기] → 자식 트랙이 시작되는 지점의 모서리가 둥글게(`╰`류) 그려짐
- 1.2: [가로 모드(LR/RL), 병합] → 합류해 들어오는(source) 트랙 쪽 모서리가 둥글게(`╯`류) 그려짐
- 1.3: [세로 모드(TB/BT), 분기] → 자식 트랙이 시작되는 지점의 모서리가 둥글게(`╮`류) 그려짐
- 1.4: [세로 모드(TB/BT), 병합] → 합류해 들어오는(source) 트랙 쪽 모서리가 둥글게(`╯`류) 그려짐
- 1.5: [한 지점에서 브랜치 3개 이상이 동시에 갈라지거나 합쳐짐(T자·교차 지점)] → 기존과 동일한
  문자로 그려짐(변경 없음)
- 1.6: [`--style none`] → 색상 비활성화와 무관하게 모서리가 둥글게 그려짐

### 2. 세로 모드 커밋 id 간격
- 2.1: [세로 모드, 분기가 부모의 가장 최근 커밋과 같은 행에서 일어남] → 그 커밋의 id 글자와
  분기 연결선 사이에 최소 한 칸 공백이 생김
- 2.2: [가로 모드] → 기존과 동일(이 문제가 재현되지 않으므로 변경 없음)

### 3. 회귀
- 3.1: [기존 `gitgraph.rs` 테스트] → 전량 통과(모서리 문자를 직접 비교하던 테스트는 둥근 문자
  기대값으로 조정)
- 3.2: [항상] → 어떤 입력에도 패닉하지 않음
- 3.3: [`examples/gitgraph-vertical.md`, `examples/architecture.md`] → 패닉 없이 다시
  렌더링됨(육안 확인용)

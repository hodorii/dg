# Requirements — mermaid-chart-foundation

## 정의
`pie`/`xychart-beta`/`gantt`/`quadrantChart` 등 여러 수치 차트를 다루는 사람을 위해, 축·막대·범례·수치 표기를 모든 차트에서 동일한 규칙으로 그려주는 공통 렌더링 규칙이다.

## Boundary Context
- **In scope**: 축(눈금·라벨) 표시 규칙, 막대/바 길이 비례 표시 규칙, 범례(항목명+값) 표시 규칙, 수치 포맷팅 규칙(정수/소수/백분율), 값 없음·음수 등 공통 예외 처리, 표시 실패 시 일반 코드블록 대체
- **Out of scope**: 개별 차트 종류(`pie`/`xychart-beta`/`gantt`/`quadrantChart`)의 문법 파싱, 색상 커스터마이징

## Acceptance Criteria

### 1. 축 표시
- 1.1: [수치 축 범위(최소~최대) 지정] → 축 위에 일정 간격의 눈금과 값이 표시됨
- 1.2: [축 제목 지정] → 축 근처에 제목 텍스트가 표시됨
- 1.3: [축 범위 미지정] → 데이터 값 범위로부터 자동 계산된 축 범위가 표시됨

### 2. 막대 표시
- 2.1: [항목별 수치 값 목록] → 각 항목이 값 크기에 비례한 길이의 막대로 표시됨
- 2.2: [모든 값이 0] → 막대 없이 항목명만 표시됨(오류 없음)
- 2.3: [값에 음수 포함] → 기준선 좌우(또는 상하)로 방향이 구분되어 표시됨

### 3. 범례
- 3.1: [항목명과 값 목록] → 항목명과 값이 함께 표시됨
- 3.2: [항목명이 표시 폭보다 김] → 잘리거나 줄바꿈되어 레이아웃이 깨지지 않고 표시됨

### 4. 수치 포맷팅
- 4.1: [값이 정수] → 소수점 없이 표시됨
- 4.2: [값이 소수] → 일정한 소수 자리수로 표시됨
- 4.3: [비율(백분율) 표기가 필요한 차트] → 총합 대비 백분율이 표시됨

### 5. 경계/오류 처리
- 5.1: [항목 수가 표시 가능한 공간을 초과] → 초과분은 생략 표시(예: "외 N개")되거나 전체가 일반 코드블록으로 대체 표시됨
- 5.2: [항목이 하나도 없음] → 빈 차트 틀만 표시되거나 일반 코드블록으로 대체 표시됨
- 5.3: [항상] → 어떤 입력 조합에도 비정상 종료(패닉)하지 않음

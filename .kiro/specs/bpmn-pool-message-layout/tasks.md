# 구현 계획 - bpmn-pool-message-layout

## 정의
버그픽스 순서(재현 테스트, 불변 테스트, 수정, 양쪽 통과)로 설계를 구현하는 계획이다. 3.2~3.7은 2026-10-08 설계 재검토로 되돌린다(근거 `research.md`). 새 수정은 3.8부터이며 steering `diagram-architecture.md`의 규칙을 BPMN에 켜는 증분 I0다(실행 순서: 3.8 → 1.4·1.5·2.2 → 3.9 → 3.10~3.15 → 4.1 → 4.2). 작업마다 검토에서 v0.4.0 대비 CPU 시간과 최대 RSS를 함께 본다.

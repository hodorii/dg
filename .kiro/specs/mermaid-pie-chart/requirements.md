# Requirements — mermaid-pie-chart

## 정의
비율 데이터를 mermaid `pie` 문법으로 표현하려는 사용자를 위해, 코드펜스 안 `pie` 소스를 항목별 막대와 백분율로 이루어진 터미널 텍스트 차트로 그려주는 기능이다.

## Boundary Context
- **In scope**: `pie` 판별, `title`, `showData` 옵션, `"항목" : 값` 목록 파싱, 백분율 계산·표시, 공통 차트 렌더링 규칙 적용, 표시 실패 시 일반 코드블록 대체
- **Out of scope**: 실제 원형(동그라미) 그래픽 표현, 3D·도넛 등 변형 표기

## Acceptance Criteria

### 1. 종류 판별
- 1.1: [첫 지시어가 pie(showData 접미 포함, 대소문자 무관)] → pie 종류로 판별되어 렌더링 시도됨

### 2. 데이터 표시
- 2.1: ["항목" : 값 목록] → 각 항목의 이름과 값(또는 백분율)이 함께 표시됨
- 2.2: [pie title <제목> 지정] → 차트 위 또는 캡션 옆에 제목이 표시됨
- 2.3: [showData 옵션 포함] → 항목마다 원본 값이 함께 표시됨
- 2.4: [showData 옵션 없음] → 항목마다 백분율이 표시됨

### 3. 비교 표시
- 3.1: [항목이 여러 개] → 값 크기에 비례한 막대 길이 차이로 항목 간 비율을 구분할 수 있게 표시됨

### 4. 경계/오류 처리
- 4.1: [값이 모두 0이거나 항목이 없음] → 오류 없이 빈 목록 또는 일반 코드블록으로 대체 표시됨
- 4.2: [항목명에 이스케이프된 큰따옴표 포함] → 이스케이프가 풀린 원래 텍스트로 표시됨
- 4.3: [렌더링 결과 폭이 표시 가능한 폭 초과] → 일반 코드블록으로 대체 표시됨
- 4.4: [항상] → 어떤 입력에도 비정상 종료(패닉)하지 않음

# Requirements — mermaid-gantt

## 정의
일정과 작업 기간을 mermaid `gantt` 또는 PlantUML `@startgantt` 문법으로 표현하려는 사용자를 위해, 코드펜스 안 소스를 섹션·작업별 타임라인 막대로 이루어진 터미널 텍스트 차트로 그려주는 기능이다.

## Boundary Context
- **In scope**:
  - mermaid: `gantt` 판별, `title`, `dateFormat`, `section`, 작업 줄(이름·id·시작일 또는 `after` 참조·기간) 파싱
  - PlantUML: `@startgantt`/`@endgantt` 판별, `Project starts`, `[작업명] requires N days`(`week`/`and` 결합 포함), `starts`/`ends`(절대·상대 `D+N`), `then`(순차 연결), `starts at [다른 작업]'s end`류 제약, `title`
  - 두 언어 모두: 타임라인 막대 배치는 같은 렌더링 규칙(공통 차트 렌더링 기반)을 공유해 결과가 시각적으로 동등하게 나옴, 표시 실패 시 일반 코드블록 대체
- **Out of scope**: 마일스톤 아이콘·자원 배정(`on {Alice}`)·색상 지정(`is colored in`)·완료율(`% completed`)·주말/휴일 강조(`is closed`)·`critical` 등 강조 스타일 — 두 언어 모두 파싱 시 오류 없이 무시

## Acceptance Criteria

### 1. 종류 판별
- 1.1: [첫 지시어가 gantt] → gantt 종류로 판별되어 렌더링 시도됨

### 2. 기본 구조
- 2.1: [section <이름> 지정] → 해당 섹션 아래 작업들이 그룹으로 구분되어 표시됨
- 2.2: [작업 줄에 이름과 기간 지정] → 작업 이름과 함께 기간에 비례한 길이의 타임라인 막대가 표시됨
- 2.3: [dateFormat 지정] → 날짜가 해당 형식으로 해석되어 타임라인에 반영됨

### 3. 일정 관계
- 3.1: [after <작업id> 참조] → 참조한 작업이 끝나는 시점부터 이어서 막대가 표시됨
- 3.2: [시작일을 직접 지정] → 지정한 날짜 위치에서 막대가 시작됨
- 3.3: [존재하지 않는 작업id를 after로 참조] → 오류 없이 해당 작업이 처음(또는 기준일)부터 시작하는 것으로 처리되거나 일반 코드블록으로 대체 표시됨

### 4. 제목
- 4.1: [title <텍스트> 지정] → 차트 위에 제목이 표시됨

### 5. 경계/오류 처리
- 5.1: [작업 기간이 표시 가능한 가로 폭 대비 매우 김] → 전체 기간이 폭에 맞춰 축소 비례하여 표시됨
- 5.2: [작업 수가 표시 가능한 세로 공간을 초과] → 초과 작업은 생략 표시되거나 일반 코드블록으로 대체 표시됨
- 5.3: [항상] → 어떤 입력에도 비정상 종료(패닉)하지 않음

### 6. PlantUML 판별과 파싱
- 6.1: [코드펜스가 `@startgantt`로 시작] → 본문에 `[`로 시작하는 줄(작업 선언)이 있어도 component/class 등 다른 종류의 휴리스틱 판별과 무관하게 gantt로 즉시 판별되어 렌더링 시도됨(PlantUML 언어로)
- 6.2: [`[작업명] requires N days`(또는 `week`, `and` 결합) 지정] → 기간에 비례한 타임라인 막대가 표시됨
- 6.3: [`[작업명] starts <날짜 또는 D+N>` 지정] → 지정한 시점에서 막대가 시작됨
- 6.4: [`[작업1] requires ... then [작업2] requires ...` 순차 연결] → 작업2가 작업1이 끝나는 시점부터 이어서 표시됨
- 6.5: [`Project starts <날짜>` 지정] → 그 날짜가 타임라인의 기준일이 됨
- 6.6: [mermaid `gantt`와 PlantUML `@startgantt`로 동일한 일정을 표현] → 두 결과가 같은 렌더링 규칙(축·막대 비례)을 따라 시각적으로 동등하게 표시됨

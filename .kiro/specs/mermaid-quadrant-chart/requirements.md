# Requirements — mermaid-quadrant-chart

## 정의
두 축 기준으로 항목을 4개 영역에 배치해 비교하려는 사용자를 위해, 코드펜스 안 `quadrantChart` 소스를 4분면 좌표 배치 형태의 터미널 텍스트 차트로 그려주는 기능이다.

## Boundary Context
- **In scope**: `quadrantChart` 판별, `title`, `x-axis`/`y-axis` 양끝 라벨, `quadrant-1`~`quadrant-4` 라벨, `"항목": [x, y]` 좌표 데이터, 공통 차트 렌더링 규칙 적용, 표시 실패 시 일반 코드블록 대체
- **Out of scope**: 점 크기·색상으로 추가 차원을 표현, 애니메이션

## Acceptance Criteria

### 1. 종류 판별
- 1.1: [첫 지시어가 quadrantChart] → quadrant 종류로 판별되어 렌더링 시도됨

### 2. 사분면 틀
- 2.1: [quadrant-1~4에 라벨 지정] → 4개 영역 각각에 해당 라벨이 표시됨
- 2.2: [x-axis/y-axis에 양끝 라벨 지정] → 가로·세로 축 양 끝에 라벨이 표시됨
- 2.3: [일부 quadrant 라벨 생략] → 생략된 영역은 빈 상태로, 나머지는 정상 표시됨

### 3. 항목 배치
- 3.1: ["항목": [x, y] 좌표(0~1 범위) 데이터] → 좌표 비율에 맞는 위치에 항목 이름(또는 점)이 표시됨
- 3.2: [두 항목의 좌표가 같거나 매우 가까움] → 서로 겹치지 않고 구분 가능하게 표시됨

### 4. 제목
- 4.1: [title <텍스트> 지정] → 차트 위에 제목이 표시됨

### 5. 경계/오류 처리
- 5.1: [좌표 값이 0~1 범위를 벗어남] → 범위 안쪽으로 보정되어 표시되거나 일반 코드블록으로 대체 표시됨
- 5.2: [항목 수가 표시 가능한 공간을 초과] → 초과 항목은 생략 표시되거나 일반 코드블록으로 대체 표시됨
- 5.3: [항상] → 어떤 입력에도 비정상 종료(패닉)하지 않음
